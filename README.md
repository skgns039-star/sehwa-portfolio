# 세화건설 사업분야 포트폴리오 위젯

아임웹 "코드" 위젯에 붙여넣는 포트폴리오 섹션입니다.
대분류 5개 그리드, 클릭하면 소분류 탭과 시공 사진 갤러리가 열립니다.

## 폴더 구성

- `widget.html` : 아임웹에 붙여넣을 전체 코드 (CSS + HTML + JS 단일 파일)
- `images/` : 웹용으로 최적화한 시공 사진 (최대 1600px, 용량 축소, 영문 폴더명)
- `manifest.json` : 원본 파일명과 변환된 파일명 대응표

로컬 미리보기: `widget.html`을 더블클릭하면 브라우저에서 바로 확인됩니다.
(기본 이미지 주소가 옆의 `images/` 폴더를 가리키도록 되어 있습니다)

## 아임웹에 올리는 순서

이미지는 GitHub Pages에 이미 올려두었고 `widget.html`의 이미지 주소도 연결해 두었습니다.
- 이미지 호스팅: https://skgns039-star.github.io/sehwa-portfolio/images/
- 원본 저장소: https://github.com/skgns039-star/sehwa-portfolio

남은 일은 한 가지입니다.
1. 아임웹 편집기에서 위젯 추가 → 코드 → `widget.html` 내용 전체를 붙여넣고 저장합니다.

사진을 추가하거나 바꾸려면 저장소의 `images/` 폴더를 수정한 뒤 푸시하면 됩니다.
호스팅을 다른 곳으로 옮기면 `widget.html` 스크립트 상단의 `IMG_BASE` 값만 바꾸면 됩니다.

## 확인 사항

- 사진은 폴더당 `01.jpg`, `02.jpg` 순번으로 이름이 바뀌어 있습니다. 원본과의 대응은 `manifest.json` 참고.
- 사진 방향(세로/가로)은 변환 시 자동 보정했습니다.
- 갤러리는 지연 로딩(lazy loading)이라 열어본 탭의 사진만 내려받습니다.
